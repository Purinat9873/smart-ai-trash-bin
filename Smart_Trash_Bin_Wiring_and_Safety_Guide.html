1. สถาปัตยกรรมระบบแบบ Dual-Engine (System Overview)

ระบบถังขยะอัจฉริยะนี้ถูกออกแบบให้ทำงานได้ทั้งแบบมีคอมพิวเตอร์และไม่มีคอมพิวเตอร์:

🔋 โหมด Standalone 100% (ไร้สาย / ไม่ต่อ Laptop)

เมื่อเปิดสวิตช์ไฟ บอร์ด ESP32-S3 เชื่อมต่อกล้องผ่าน Wi-Fi ในตัวอัตโนมัติ และใช้สมองกล Autonomous Standalone Engine วิเคราะห์จำแนกขยะบนตัวบอร์ดได้เอง พร้อมระบบวัดถังเต็มและเปิดเซอร์โวโดยไม่ต้องมีคอมพิวเตอร์

💻 โหมดเชื่อมต่อ Laptop (High-Accuracy YOLOv8)

เมื่อเสียบสาย USB เข้าคอมพิวเตอร์และรัน RUN_SMART_BIN_LIVE.bat ระบบจะส่งภาพด้วยความเร็วสูง 921,600 baud ให้โมเดล Custom YOLOv8 บนคอมพิวเตอร์วิเคราะห์ และโชว์ผลลัพธ์ผ่านหน้าเว็บ Dashboard สดๆ

วงจรการทำงานอัตโนมัติ: ขยะจ่อหน้าเซนเซอร์ IR (GPIO 0) ➔ OLED นับถอยหลัง 3..2..1 (800ms) ➔ กล้อง OV2640 ถ่ายภาพ ➔ วิเคราะห์ 4 คลาส ➔ เช็คอัลตราโซนิคของถังช่องนั้น ➔ หากถังเต็ม: ล็อกฝาถังและกระพริบเตือน !! BIN FULL ALERT !! / หากถังว่าง: เซอร์โวเปิด 90° ค้างไว้ 3.5 วินาที

2. ระบบการจ่ายพลังงานและกราวด์ร่วม (Power Supply & Common GND)

⚠️ กฎเหล็กที่สำคัญที่สุดของระบบฮาร์ดแวร์ (ห้ามละเลยเด็ดขาด):
  1. ห้ามดึงไฟ 5V หรือ 3.3V จากขาของบอร์ด ESP32 ไปเลี้ยงมอเตอร์เซอร์โวเด็ดขาด: มอเตอร์ SG90 ทั้ง 4 ตัวกินกระแสกระชาก (Stall Current) สูงถึง 500mA - 800mA ต่อตัว หากดึงไฟจากบอร์ด ชิปจะไฟตก รีเซ็ตวน หรือพังเสียหายทันที
  2. ต้องต่อกราวด์ร่วม (Common Ground) ถึงกัน 100%: ขั้วลบ (GND) ของแหล่งจ่ายไฟ, ขา OUT- ของ Step-down, ขา GND ของ ESP32-S3, ขา GND ของ ESP32-CAM, สายสีน้ำตาลของเซอร์โวทั้ง 4 ตัว และขา GND ของเซนเซอร์ทุกตัว ต้องเชื่อมถึงกันทั้งหมด
[ แหล่งจ่ายไฟหลัก 7.4V - 12V (แบตเตอรี่ 2S หรือ Adapter 2A-3A) ] │ ├── (+) ขั้วบวก ───────────────► เข้า [ IN+ ] ของ Step-Down (LM2596) └── (-) ขั้วลบ (GND) ──────────► เข้า [ IN- ] ของ Step-Down (LM2596) │ [ ปรับจูนหมุนให้ได้ 5.0V DC เป๊ะ ] │ ┌────────────────────────────────────────────────┴────────────────────────────────┐ │ 🔴 รางไฟบวก 5.0V Rail (ต่อเข้า 5V ของ S3, 5V ของ CAM, VCC เซอร์โว 4 ตัว, VCC เซนเซอร์ทุกตัว) │ ├─────────────────────────────────────────────────────────────────────────────────┤ │ ⚫ รางกราวด์ Common GND (เชื่อมขา GND ของอุปกรณ์ทุกตัวในระบบถึงกันทั้งหมด 100%) │ └─────────────────────────────────────────────────────────────────────────────────┘

3. ตารางการต่อสายฮาร์ดแวร์แบบละเอียดทุกพิน (Complete Pinout Table)

3.1 หน้าจอ OLED 0.96" I2C (SSD1306) & เซนเซอร์ตรวจจับขยะ (FC-51 IR)

GND Common GND กราวด์ร่วม

3.2 มอเตอร์เซอร์โวเปิด-ปิดฝาถังขยะ 4 ช่อง (SG90 Micro Servos)

*สายเซอร์โว: สีแดง ➔ 5.0V Rail, สีน้ำตาล ➔ Common GND, สายสีส้ม (PWM) ➔ เข้าบอร์ด ESP32-S3 ดังนี้:*

ถังขยะประจำช่อง ประเภทขยะ สีฝาถัง พินสัญญาณ (สายสีส้ม) พินไฟเลี้ยง (สายสีแดง/น้ำตาล)
ช่องที่ 1 ขยะทั่วไป (General) สีน้ำเงิน (Blue) GPIO 21 5.0V Rail / Common GND
ช่องที่ 2 ขยะรีไซเคิล (Recyclable) สีเหลือง (Yellow) GPIO 38 5.0V Rail / Common GND
ช่องที่ 3 ขยะเปียก (Organic / Wet) สีเขียว (Green) GPIO 39 5.0V Rail / Common GND
ช่องที่ 4 ขยะอันตราย (Hazardous) สีแดง (Red) GPIO 40 5.0V Rail / Common GND

3.3 เซนเซอร์อัลตราโซนิคตรวจวัดถังเต็ม 4 ช่อง (HC-SR04)

*ติดตั้งใต้ฝาถังส่องลงก้นถัง | ขา Trig ต่อพ่วงร่วมกันเข้า GPIO 14 | ขา Echo ผ่านวงจรแบ่งแรงดัน (1kΩ/2kΩ):*

ตำแหน่งติดตั้ง พิน VCC / GND พิน Trigger (ยิงคลื่น) พิน Echo (รับคลื่น) เกณฑ์ตรวจจับถังเต็ม
ถังขยะทั่วไป (General) 5.0V / GND GPIO 14 (พ่วงร่วม) GPIO 47 (ผ่าน 1k+2k) ระยะผิวขยะ ≤ 8.0 ซม.
ถังขยะรีไซเคิล (Recyclable) 5.0V / GND GPIO 14 (พ่วงร่วม) GPIO 48 (ผ่าน 1k+2k) ระยะผิวขยะ ≤ 8.0 ซม.
ถังขยะเปียก (Organic) 5.0V / GND GPIO 14 (พ่วงร่วม) GPIO 3 (ผ่าน 1k+2k) ระยะผิวขยะ ≤ 8.0 ซม.
ถังขยะอันตราย (Hazardous) 5.0V / GND GPIO 14 (พ่วงร่วม) GPIO 44 (ผ่าน 1k+2k) ระยะผิวขยะ ≤ 8.0 ซม.
⚡ วงจรแบ่งแรงดันขา Echo (Voltage Divider 5V ➔ 3.3V):
ขา Echo ของ HC-SR04 ปล่อยแรงดัน 5.0V แต่ขา GPIO ของ ESP32-S3 รับได้สูงสุด 3.3V เพื่อความปลอดภัยระยะยาว ให้ต่อตัวต้านทานดังนี้:
Echo (5V) ──[ ตัวต้านทาน 1kΩ ]──┬── เข้าขา GPIO ของ ESP32-S3 (3.3V)
└──[ ตัวต้านทาน 2kΩ ]── เข้ากราวด์ (Common GND)

4. 5 ข้อควรระวังและเทคนิคประกอบลงตู้จริง (Critical Pro Tips)

1. น้ำหนักฝาถังกับแรงบิดเซอร์โว SG90 (จุดที่ผิดพลาดบ่อยที่สุด!)

มอเตอร์เซอร์โว SG90 9g มีแรงบิดจำกัดเพียง ~1.6 kg·cm และใช้เฟืองพลาสติก ฝาถังต้องใช้วัสดุน้ำหนักเบาเท่านั้น เช่น ฟิวเจอร์บอร์ด แผ่นอะคริลิกบาง 1.5mm หรือพลาสติก 3D Print แบบบาง หากฝาถังหนาหรือหนัก มอเตอร์จะยกไม่ขึ้นหรือเฟืองรูดเสียหายได้ทันที (วิธีแก้: ติดสปริงช่วยดึงลดแรงต้าน หรือเปลี่ยนเป็นเซอร์โวเฟืองโลหะรุ่น MG90S หรือ MG996R)

2. ตัวเก็บประจุกันไฟกระชาก (Decoupling Capacitor)

เมื่อเซอร์โวเริ่มหมุนเปิดฝาพร้อมกัน หรือกล้องส่งคลื่น Wi-Fi จะเกิดกระแสกระชากชั่วขณะ ทำให้แรงดันไฟ 5V วูบลง สิ่งที่ควรทำ: ต่อตัวเก็บประจุแบบอิเล็กโทรไลต์ขนาด 470µF – 1000µF (10V หรือ 16V) คร่อมขั้วบวก (+) และขั้วลบ (-) ของรางไฟ 5V ใกล้ๆ จุดต่อเซอร์โวเพื่อทำหน้าที่เป็นถังพักพลังงานสำรอง

3. การปรับระยะโฟกัสของเลนส์กล้อง OV2640

กล้อง OV2640 จากโรงงานถูกหมุนปรับโฟกัสไว้ที่ระยะอนันต์ (1-2 เมตร) เมื่อนำขยะมาจ่อที่แท่นสแกนระยะใกล้ (~15-25 ซม.) ภาพถ่ายจะเบลอ ทำให้ AI จำแนกผิดพลาด วิธีแก้: ใช้นิ้วค่อยๆ หมุนเกลียวเลนส์ของตัวกล้องเพื่อปรับระยะโฟกัสให้ภาพวัตถุที่ระยะ 20 ซม. คมชัดที่สุด

4. ข้อควรระวังเรื่องขาบูต GPIO 0 (Boot Strapping Pin)

ขาเซนเซอร์ IR ต่ออยู่ที่ GPIO 0 ซึ่งเป็นขา Strapping Pin เข้าสู่โหมดเบิร์นโปรแกรมของ ESP32 ข้อควรจำ: ในจังหวะที่กดสวิตช์เปิดไฟเข้าเครื่อง ห้ามมีสิ่งของหรือมือไปบังหน้าเซนเซอร์ IR เด็ดขาด (ให้แท่นสแกนโล่งๆ ตอนเปิดเครื่อง) มิฉะนั้นบอร์ดจะไม่ยอมบูตเข้าสู่โปรแกรมหลัก

5. แสงสว่างบริเวณแท่นสแกนขยะ (Lighting Condition)

กล้อง OV2640 ทำงานได้ดีในที่ที่มีแสงสว่างเพียงพอ หากแท่นสแกนอยู่ใต้เงามืดหรือใต้ฝาตู้ ภาพจะมืดและเกิดสัญญาณรบกวน (Noise) สูง แนะนำให้ติดตั้งหลอดไฟ LED สีขาวดวงเล็กๆ ส่องสว่างลงมาที่จุดวางขยะ จะเพิ่มความแม่นยำในการคัดแยกขยะได้สูงกว่า 95%

5. ลำดับขั้นตอนการเปิดเครื่องและทดสอบ (Startup Checklist)

  1. วัดไฟก่อนเสียบอุปกรณ์: ใช้มัลติมิเตอร์วัดไฟขาออกจากโมดูล Step-Down ต้องได้ 5.0V ± 0.1V
  2. เปิดสวิตช์ไฟหลัก: ESP32-CAM จะบูตและปล่อย Wi-Fi ESP32-CAM-MB | จอ OLED จะขึ้น CONNECTING... ➔ [ READY ]
  3. ตรวจสอบสถานะ 4 ถังบนจอ OLED: บรรทัดล่างจะขึ้น G:OK R:OK W:OK H:OK (หากยังไม่ต่ออัลตราโซนิคตัวไหน ระบบจะอ่านได้ -1.0cm และถือว่าว่าง (OK) ป้องกันการล็อกฝาถังผิดพลาด)
  4. ทดสอบยื่นขยะ: นำขยะจ่อหน้าเซนเซอร์ IR ➔ จอนับถอยหลัง 3..2..1 ➔ ถ่ายภาพ ➔ วิเคราะห์ ➔ ฝาถังช่องนั้นเปิด 90° ค้าง 3.5 วินาทีแล้วปิดกลับ
  5. ทดสอบระบบถังเต็ม: นำวัตถุไปบังหน้าอัลตราโซนิคของถังใดถังหนึ่งที่ระยะต่ำกว่า 8 ซม. ➔ จอ Standby จะเปลี่ยนเป็น !FULL ➔ เมื่อสแกนขยะประเภทนั้น จอจะกระพริบเตือน !! BIN FULL ALERT !! และฝาถังจะไม่เปิดเด็ดขาด!
