# ผังวงจรและการต่อขา GPIO (Pinout & Circuit Documentation)

เอกสารนี้ระบุการเชื่อมต่อวงจรอย่างละเอียดสำหรับโปรเจกต์ถังขยะอัจฉริยะคัดแยก 4 ประเภทด้วย AI บนบอร์ด **ESP32-S3 (N16R8)**

## 2. วงจรแบ่งแรงดันขา Echo (Voltage Divider Circuit)

สัญญาณ Echo ของ HC-SR04 มีแรงดัน 5.0V ซึ่งสูงเกินกว่าพิกัดของ ESP32-S3 (สูงสุด 3.6V) ต้องต่อวงจรแบ่งแรงดันตามผังนี้สำหรับเซนเซอร์ทั้ง 4 ตัว:

```text
    HC-SR04 [Echo Pin] (5.0V)
           │
           ▼
     [ ตัวต้านทาน 1kΩ ]
           │
           ├───────────────────> ต่อเข้าขา GPIO ของ ESP32-S3 (แรงดัน ~3.33V ปลอดภัย)
           │
     [ ตัวต้านทาน 2kΩ ]
           │
           ▼
     [ รางสายกราวด์ GND ]
```

## 3. ผังระบบจ่ายไฟเสถียรสูง (2S Series + Step-Down Buck Converter)

```text
  [ ถ่าน 18650 x2 ต่ออนุกรม 7.4V - 8.4V ]
         │ (+) 7.4V                 │ (-) GND
         ▼                          ▼
    ┌────────── Step-Down Buck Module (Mini360 / LM2596) ──────────┐
    │ VIN(+)                                               VIN(-)  │
    │        [ หมุนสกรูทองเหลืองปรับแรงดันไฟออกให้ได้นิ่งที่ 5.0V ]       │
    │ VOUT(+)                                             VOUT(-)  │
    └────┬──────────────────────────────────────────────────┬─────┘
         │ (+) 5.0V เสถียรสูง                                │ GND ร่วม (Common Ground)
         ├──────────────────────────────────────────────────┼──────────────────────────────┐
         │                                                  │                              │
   ┌─────┴────────────────┐                                 │                              │
   │ ตัวเก็บประจุ (Cap)    │                                 │                              │
   │ 1000µF 16V (Low-ESR) │                                 │                              │
   │ (ขั้ว +)    (แถบเทา -)│                                 │                              │
   └─────┬────────────────┘                                 │                              │
         │                                                  │                              │
         ▼                                                  ▼                              │
   [ แถบไฟ 5V บน Breadboard ]                        [ แถบ GND บน Breadboard ]             │
         │                                                  │                              │
         ├─> ขา 5V / VIN ของ ESP32-S3                      ├─> GND ของ ESP32-S3           │
         ├─> สายสีแดง (VCC) ของ Servo ทั้ง 4 ตัว            ├─> สายน้ำตาล (GND) Servo x4   │
         ├─> VCC ของ HC-SR04 ทั้ง 4 ตัว                     ├─> GND ของ HC-SR04 ทั้ง 4 ตัว  │
         ├─> VCC ของ FC-51 ทั้ง 5 ตัว (รวมตัวหน้ากล้อง)     ├─> GND ของ FC-51 ทั้ง 5 ตัว    │
         └─> VCC ของ OLED 0.96"                             └─> GND ของ OLED 0.96"         │
                                                                                           │
                                                            └──────────────────────────────┘
```

> [!TIP]
> **ขั้นตอนการปรับไฟ:** ก่อนเสียบสายไฟเข้า ESP32-S3 และอุปกรณ์อื่นๆ ให้ใช้มัลติมิเตอร์วัดที่ขั้ว `VOUT(+)` และ `VOUT(-)` ของโมดูล Step-Down แล้วหมุนสกรูตัวต้านทานปรับค่าได้ (Trimpot) จนมิเตอร์อ่านค่าได้ **5.0V – 5.1V** พอดี
