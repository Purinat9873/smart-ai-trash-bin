# คู่มือการปรับแต่งและการแก้ไขปัญหา (Calibration & Troubleshooting Guide)

เอกสารนี้จะแนะนำการปรับแต่งฮาร์ดแวร์จริงสำหรับตัวถังต้นแบบกระดาษลังและฝาฟิวเจอร์บอร์ด

---

## 1. การปรับแต่งเซนเซอร์ FC-51 (IR Obstacle Sensors)

เซนเซอร์ FC-51 มีตัวต้านทานปรับค่าได้ (Trimpot สีฟ้า) สำหรับปรับความไวของแสงสะท้อน:

### 1.1 เซนเซอร์หน้ากล้อง (Auto-Scan - GPIO 0)
* **เป้าหมาย:** ให้เซนเซอร์ตรวจจับมือหรือขยะที่เข้ามาในระยะ **15–20 ซม.** เท่านั้น หากอยู่ไกลกว่านั้นต้องไม่ตรวจจับ
* **วิธีปรับ:**
  1. เปิดไฟเลี้ยงระบบ หรือรันสเก็ตช์ `tests/hardware_tests/02_sensors_test/`
  2. ยื่นมือถือขยะไว้ที่ระยะ 18 ซม. หน้าเลนส์
  3. ใช้ไขควงแบนหมุน Trimpot สีฟ้าจนกระทั่ง **LED สีเขียวบนโมดูลเพิ่งเริ่มสว่าง**
  4. ดึงมือออก ไฟเขียวต้องดับสนิททันที

### 1.2 เซนเซอร์ตรวจขยะหล่น (ปากถัง 4 ช่อง - GPIO 41, 42, 45, 46)
* **ปัญหาบนกระดาษลัง:** ผิวกระดาษลังสีน้ำตาลสะท้อนแสง IR ได้ปานกลาง หากหันเซนเซอร์ลงก้นถัง แสงอาจสะท้อนกลับมาทำให้เซนเซอร์ติดค้างตลอดเวลา
* **วิธีแก้:**
  1. **ต้องติดตั้งในแนวนอนขนานกับปากถัง** (ส่องข้ามปากถังไปผนังฝั่งตรงข้าม)
  2. หมุน Trimpot ทวนเข็มนาฬิกาจนกว่าไฟ LED สีเขียวจะดับสนิท (ในสภาวะที่ไม่มีขยะ)
  3. ทดลองหย่อนขวดพลาสติกหรือเศษกระดาษผ่านปากถัง ไฟเขียวต้องสว่างวาบขึ้นเฉพาะตอนขยะตัดผ่าน

## 2. การปรับแต่งเซนเซอร์วัดขยะเต็ม (HC-SR04 Ultrasonic)

* **ความลึกของกล่องกระดาษลัง:** ปกติกล่องพัสดุขนาดกลางจะลึกประมาณ 25–30 ซม.
* **ตำแหน่งติดตั้ง:** ติดไว้บนคานด้านบน ส่องลงมาตรงกลางช่องถัง
* **การตั้งเกณฑ์ (Threshold):**
  * ในไฟล์ `smart_trash_bin.ino` กำหนดค่า:
    ```cpp
    #define FULL_BIN_THRESHOLD_CM 7.0
    ```
  * หากกล่องของคุณตื้นกว่า (เช่น ลึก 18 ซม.) ให้ปรับเป็น `5.0`
  * หากกล่องของคุณลึกกว่า (เช่น ลึก 35 ซม.) ให้ปรับเป็น `8.0` หรือ `10.0`
* **การป้องกันคลื่นสะท้อนชนขอบกล่อง:** หากช่องถังแคบ ให้ติดตั้งเซนเซอร์ตรงกึ่งกลางปากช่อง และหันหน้าทรานสดิวเซอร์ให้ตั้งฉากกับก้นกล่อง

## 3. การปรับแต่งกลไกฝาถังและ Servo SG90

1. **การตั้งศูนย์องศา (Zero Position Calibration):**
   * รันสเก็ตช์ `tests/hardware_tests/01_servo_test/`
   * มอเตอร์จะหมุนไปที่ตำแหน่ง `0 องศา` ให้ถอดแขนเซอร์โว (Servo Horn) ออกมา แล้วเสียบกลับเข้าไปใหม่ในมุมที่ฝาถังปิดสนิทพอดี
   * ขันสกรูยึดแขนเซอร์โวให้แน่น
2. **บานพับฝาฟิวเจอร์บอร์ด:**
   * ให้ใช้เทปผ้า (Duct Tape) ติดประกบด้านบนและด้านล่างของจุดพับ
   * บานพับที่ดีต้องสามารถใช้นิ้วสะกิดเปิด-ปิดได้โดยไม่มีแรงต้าน
3. **ก้านกระทุ้ง (Pushrod):**
   * ใช้ลวดหนีบกระดาษดัดเป็นรูปตัว `Z` เพื่อเกี่ยวรูบนแขนเซอร์โวเข้ากับใต้ฝาฟิวเจอร์บอร์ด
   * ช่วยให้แรงบิดส่งตรงไปยังฝาถังได้อย่างมีประสิทธิภาพสูงสุด

## 4. ปัญหาที่พบบ่อยและการแก้ไข (Troubleshooting Matrix)

| อาการที่พบ | สาเหตุที่เป็นไปได้ | วิธีแก้ไข |
| :--- | :--- | :--- |
| **ESP32-S3 เกิด Panic / Boot Loop** | มีการต่อสายเข้า GPIO 33, 34, 35, 36 หรือ 37 | ถอดสายออกจากขา 33–37 ทันที ขาเหล่านี้เป็นของ Octal PSRAM |
| **ESP32-S3 รีเซ็ตตัวเองตอนมอเตอร์ขยับ** | แรงดัน 5V ตกวูบ (Brownout) | 1. ตรวจสอบว่าโมดูล Step-Down ปรับไฟไว้ที่ 5.0V–5.1V<br>2. ใส่ C 1000µF คร่อมราง 5V ใกล้เซอร์โว |
| **กล้อง OV2640 ภาพไม่ขึ้น / Init Failed** | สายแพกล้องเสียบไม่สนิท หรือไม่ได้เปิด OPI PSRAM | 1. ดันขาล็อกสายแพและเสียบสายแพให้ตรง<br>2. ใน Arduino IDE เลือก `PSRAM: OPI PSRAM` |
| **เซนเซอร์ IR ติดค้าง (ไฟเขียวติดตลอด)** | แสงสะท้อนจากผนังกระดาษลัง หรือแสงแดดส่อง | 1. หมุน Trimpot ทวนเข็มนาฬิกาเพื่อลดความไว<br>2. บังแสงภายนอกไม่ให้ส่องเข้าเซนเซอร์ตรงๆ |
| **ส่งภาพขึ้น API ไม่ได้ (HTTP Code != 200)** | Wi-Fi ไม่ต่อ หรือ API Key ผิด / ติด Rate Limit | 1. ตรวจสอบ SSID/Password<br>2. ทดสอบยิงเข้า `tests/mock_server/mock_api_server.py` ก่อน |
