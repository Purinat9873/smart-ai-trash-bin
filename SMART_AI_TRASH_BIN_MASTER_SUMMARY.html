📑 เอกสารสรุปโครงการฉบับสมบูรณ์ (Master Project Summary)

ระบบถังขยะอัจฉริยะคัดแยก 4 ประเภทด้วย AI (Smart AI 4-Class Sorting Trash Bin)

บอร์ดประมวลผล: ESP32-S3 N16R8 (16MB Flash, 8MB PSRAM) โมเดล AI: Triple-Mode (Wireless Cloud AI + Standalone Edge AI + USB Lab) สถานะระบบ: Standalone & Cloud Ready 100% (ทำงานได้ทั้งมีเน็ตและไม่มีเน็ตโดยไม่ต้องต่อคอม)
🌟 สรุปภาพรวมความสำเร็จและสถาปัตยกรรมระบบ:
ระบบสามารถตรวจจับวัตถุขยะอัตโนมัติผ่านเซนเซอร์อินฟราเรด สั่งกล้อง OV2640 ถ่ายภาพ และทำการจำแนกประเภทขยะออกเป็น 4 ประเภท (ขยะทั่วไป, ขยะรีไซเคิล, ขยะเปียก, ขยะอันตราย) สั่งเปิดฝาถังขยะช่องที่ถูกต้องด้วยเซอร์โวมอเตอร์ 4 ตัว พร้อมเซนเซอร์อัลตราโซนิคตรวจเช็คขยะเต็มและล็อกฝาถังเตือนอัตโนมัติ
โดยเฉพาะอย่างยิ่ง เมื่อถอดสายออกจากแล็ปท็อป (ไม่ต่อคอม) ระบบสามารถทำงานได้ 2 รูปแบบย่อยอย่างสมบูรณ์:
1. โหมดไม่ต่อคอม + มีเน็ต (Wireless Cloud AI): สลับ Wi-Fi ไปเกาะ Wi-Fi บ้าน/Hotspot มือถือ แล้วยิงภาพ JPEG ขึ้น Cloud Server (YOLOv8) แบบไร้สาย 100%
2. โหมดไม่ต่อคอม + ไม่มีเน็ต (Offline Standalone Edge AI): ประมวลผลบนชิป ESP32-S3 (TJpg_Decoder) ถอดรหัสภาพวิเคราะห์ค่าสี HSV และแสงสะท้อนขวดน้ำในตัวบอร์ดเองโดยไม่ต้องมีเน็ต

1. ข้อมูลถังขยะ 4 ประเภท และการสั่งการฮาร์ดแวร์

ช่อง 1: ทั่วไป

ชื่อ: General Waste

สีฝา: ฝาสีน้ำเงิน

เซอร์โว: GPIO 21

อัลตราโซนิค: Echo 47

ซองขนม, กล่องโฟม, ถุงพลาสติก, ทิชชู่

ช่อง 2: รีไซเคิล

ชื่อ: Recyclable

สีฝา: ฝาสีเหลือง

เซอร์โว: GPIO 38

อัลตราโซนิค: Echo 48

ขวดน้ำ PET ใส, แก้วพลาสติก, กระป๋อง

ช่อง 3: ขยะเปียก

ชื่อ: Organic / Food

สีฝา: ฝาสีเขียว

เซอร์โว: GPIO 39

อัลตราโซนิค: Echo 3

เศษอาหาร, เปลือกกล้วย, ผลไม้, ผัก

ช่อง 4: อันตราย

ชื่อ: Hazardous

สีฝา: ฝาสีแดง

เซอร์โว: GPIO 40

อัลตราโซนิค: Echo 10

ถ่านไฟฉาย, แบตเตอรี่, หลอดไฟ, แผงยา

2. สถาปัตยกรรมระบบ 3 โหมด (Triple-Mode AI Architecture)

คุณสมบัติ โหมด A: ไม่ต่อคอม + มีเน็ต
(Wireless Cloud AI)		 โหมด B: ไม่ต่อคอม + ไร้เน็ต
(Offline Standalone Edge AI)		 โหมด C: เสียบสายต่อคอม
(PC Lab & Dashboard)
สาย USB ต่อคอม ไม่ต้องเสียบสาย (ไร้สาย) ไม่ต้องเสียบสาย (ไร้สาย) เสียบสาย USB-C (Serial)
อินเทอร์เน็ต / Wi-Fi ต้องการ Wi-Fi หรือ Hotspot ไม่ต้องมีเน็ต 100% (Offline) มีหรือไม่มีก็ได้
สถานที่ประมวลผล Cloud Server (YOLOv8) บนเครือข่าย/อินเทอร์เน็ต ชิป ESP32-S3 ในตัว (PSRAM 8MB) โปรแกรมบนคอมพิวเตอร์ (Python YOLOv8)
เทคโนโลยี AI Custom YOLOv8 (smart_bin_best.pt) ความแม่นยำ 99.7% (Recall 100%, mAP50: 99.5%) TJpg_Decoder วิเคราะห์ค่าสี HSV + จุดสะท้อนแสงผิวมัน (Specular) Custom YOLOv8 พร้อมหน้าต่างแสดงผล Dashboard สด
ความเร็วประมวลผล ~3.0 - 4.0 วินาที (สลับ Wi-Fi ส่งภาพ) ~20 - 80 มิลลิวินาที (รวดเร็วทันใจ) ~0.3 - 0.5 วินาที (ส่งตรงผ่านสาย USB)
จุดเด่นและการใช้งาน ตั้งถังขยะจุดไหนก็ได้ในบ้าน/อาคาร ได้โมเดล AI ตัวแม่นยำสูงสุด อัปเดตโมเดลได้ พกพาไปตั้งกลางแจ้ง นอกสถานที่ ไฟดับ หรือเน็ตล่มก็ทำงานได้ 100% ไม่มีสะดุด สาธิตงานพรีเซนต์ โชว์ภาพขึ้นจอคอมใหญ่ และเก็บภาพสแกนเข้าดาต้าเซ็ต

อุปกรณ์ ขาบนอุปกรณ์ เชื่อมต่อไปยัง พินบน ESP32-S3 หน้าที่และข้อกำหนด
จอแสดงผล OLED 0.96"
(I2C SSD1306, 0x3C)		 VCC 5V Rail หรือ 3.3V - ไฟเลี้ยงจอแสดงผล
GND Common GND GND กราวด์ร่วมระบบ
SDA ขาข้อมูล I2C GPIO 1 ส่งข้อมูลภาพ/ตัวอักษร
SCL ขานาฬิกา I2C GPIO 2 สัญญาณ Clock I2C
เซนเซอร์อินฟราเรด FC-51
(ตรวจขยะหน้ากล้อง)		 VCC 5V Rail หรือ 3.3V - ไฟเลี้ยงเซนเซอร์
GND Common GND GND กราวด์ร่วมระบบ
OUT ขาสัญญาณทริกเกอร์ GPIO 0 เมื่อมีวัตถุจ่อ ส่งสัญญาณ LOW (Active-Low)
เซอร์โวมอเตอร์ 4 ตัว
(SG90 9g เปิด-ปิดฝา)		 Servo 1 (ทั่วไป) สัญญาณ สายสีส้ม/เหลือง GPIO 21 เปิดฝาถังขยะทั่วไป 90 องศา (3.5 วินาที)
Servo 2 (รีไซเคิล) สัญญาณ สายสีส้ม/เหลือง GPIO 38 เปิดฝาถังขยะรีไซเคิล 90 องศา (3.5 วินาที)
Servo 3 (ขยะเปียก) สัญญาณ สายสีส้ม/เหลือง GPIO 39 เปิดฝาถังขยะเปียก 90 องศา (3.5 วินาที)
Servo 4 (อันตราย) สัญญาณ สายสีส้ม/เหลือง GPIO 40 เปิดฝาถังขยะอันตราย 90 องศา (3.5 วินาที)
ไฟเลี้ยงเซอร์โว (ทุกตัว) สายสีแดง (VCC) แบตเตอรี่ / แหล่งจ่ายแยก 5V - ห้ามดึงไฟจากบอร์ด ESP32-S3 เด็ดขาด! ป้องกันไฟตกบอร์ดรีเซ็ต
กราวด์เซอร์โว (ทุกตัว) สายสีน้ำตาล/ดำ Common GND ร่วม GND ต้องต่อขั้วลบถึงขั้วลบของ ESP32-S3 ทุกเส้น
เซนเซอร์อัลตราโซนิค 4 ตัว
(HC-SR04 ตรวจขยะเต็ม)		 TRIG ร่วม (ทุกตัว) ต่อรวมกันทั้ง 4 ตัว GPIO 14 ยิงคลื่นเสียงพร้อมกันทั้ง 4 ช่องถัง
Echo 1 (ทั่วไป) ผ่านตัวต้านทาน 1k+2k GPIO 47 วัดระยะผิวขยะถังทั่วไป (เตือนเมื่อ ≤ 8 ซม.)
Echo 2 (รีไซเคิล) ผ่านตัวต้านทาน 1k+2k GPIO 48 วัดระยะผิวขยะถังรีไซเคิล (เตือนเมื่อ ≤ 8 ซม.)
Echo 3 (ขยะเปียก) ผ่านตัวต้านทาน 1k+2k GPIO 3 วัดระยะผิวขยะถังขยะเปียก (เตือนเมื่อ ≤ 8 ซม.)
Echo 4 (อันตราย) ผ่านตัวต้านทาน 1k+2k GPIO 10 วัดระยะผิวขยะถังอันตราย (เตือนเมื่อ ≤ 8 ซม.)
โมดูลกล้อง ESP32-CAM
(OV2640 Wi-Fi Node)		 5V รางไฟ 5V Rail - ไฟเลี้ยงกล้องแยก ต้องการกระแสเสถียร (≥ 1A)
GND Common GND GND กราวด์ร่วม สื่อสารไร้สายผ่าน Wi-Fi ภายใน (ESP32-CAM-MB: 192.168.4.1)
⚡ ข้อควรระวังเรื่องระบบไฟฟ้า (Critical Electrical Safety):
1. ห้ามดึงไฟ 5V/3.3V จากขาบอร์ด ESP32 ไปเลี้ยงมอเตอร์เซอร์โว: เนื่องจากเซอร์โว 4 ตัวกินกระแสไฟสูง กระชากไฟได้ถึง 1A–2A ต้องใช้ไฟตรงจาก Step-Down Buck Converter (5.0V เสถียร) หรือ Power Bank จ่ายไฟแยก
2. ต้องต่อ Common Ground (GND ร่วม): ขั้วลบ (GND) ของแหล่งจ่ายไฟ, บอร์ด ESP32-S3, ESP32-CAM, มอเตอร์เซอร์โว และเซนเซอร์ทุกตัว ต้องเชื่อมต่อถึงกันทั้งหมด มิฉะนั้นมอเตอร์จะกระตุกและเซนเซอร์จะอ่านค่าผิดพลาด

4. กลไกการสลับ Wi-Fi ส่งภาพ Cloud AI เมื่อไม่ต่อคอม (Dual-Hop Flow)

📡 ขั้นตอนการทำงานไร้สายเมื่อถอดสายออกจากแล็ปท็อป (Wireless Cloud Pipeline):
1. ปกติ (Standby): ESP32-S3 เกาะสัญญาณ Wi-Fi วงปิดของบอร์ดกล้อง (ESP32-CAM-MB) ตรวจระดับถังและรอขยะ
2. เมื่อตรวจพบขยะ: นับถอยหลัง 3.. 2.. 1.. ถ่ายภาพความละเอียด 800x600 ดึงไฟล์ JPEG เข้าหน่วยความจำ RAM ในตัว
3. สลับ Wi-Fi (Hop 1): ESP32-S3 สลับไปเชื่อมต่อ Wi-Fi บ้าน (CCPP_HOME_2.4G) หรือ Hotspot มือถือ (oOKKKOo) ภายใน 1.5 วินาที
4. ส่งภาพ Cloud (Hop 2): ส่งไฟล์ JPEG ผ่าน HTTP POST ไปยังเซิร์ฟเวอร์ Cloud AI (http://192.168.1.145:5000/classify หรือ Cloud API)
5. ประมวลผล & เปิดฝา: เซิร์ฟเวอร์รัน Custom YOLOv8 ตอบผลลัพธ์กลับมา -> สั่งเปิดฝาถังขยะ 90 องศา ค้าง 3.5 วินาที
6. สลับ Wi-Fi กลับ: ESP32-S3 สลับ Wi-Fi กลับมาเกาะกล้อง OV2640 เตรียมพร้อมสำหรับการทิ้งขยะชิ้นถัดไปทันที
* หากจุดที่ตั้งไม่มีสัญญาณ Wi-Fi หรือ Cloud ไม่ตอบสนองใน 4 วิ -> ระบบจะสลับไปใช้ Onboard Edge AI บนชิปอัตโนมัติ (ไม่ค้างแน่นอน)

5. วิธีการเปิดเครื่องใช้งานจริง (Checklist 3 โหมด)

📶 แบบ 1: ไม่ต่อคอม + มีเน็ต (Wireless Cloud)

  1. เปิดคอมพิวเตอร์ที่รัน RUN_SMART_BIN_LIVE.bat ในวง Wi-Fi เดียวกัน (หรือเปิดเซิร์ฟเวอร์บน Cloud)
  2. เสียบไฟ 5V ให้ถังขยะ (Power Bank) โดยไม่ต้องเสียบสายเข้าคอม
  3. นำขยะมาจ่อหน้าเซนเซอร์ IR -> กล้องถ่ายภาพ -> สลับ Wi-Fi ยิงเข้า Cloud AI -> เปิดฝาถังตามผลลัพธ์ YOLOv8 อัตโนมัติ!

🔋 แบบ 2: ไม่ต่อคอม + ไม่มีเน็ต (Offline Edge)

  1. นำถังขยะไปตั้งที่ไหนก็ได้ (นอกบ้าน/กลางแจ้ง) ไม่ต้องมีเน็ต ไม่ต้องมีคอม
  2. เสียบไฟ 5V จาก Power Bank ก้อนเดียว
  3. รอระบบขึ้น [ READY ] ภายใน 5 วินาที
  4. นำขยะมาจ่อหน้าเซนเซอร์ -> ชิป ESP32-S3 ประมวลผลภาพบนบอร์ดเอง (TJpg_Decoder) ใน 20ms และเปิดฝาถังทันที!

💻 แบบ 3: เสียบสายต่อคอม (PC Lab & Demo)

  1. เสียบสาย USB-C จาก ESP32-S3 เข้าโน้ตบุ๊ก
  2. ดับเบิลคลิก RUN_SMART_BIN_LIVE.bat
  3. เปิดหน้าเว็บ VIEW_RESULT.html
  4. สแกนขยะแล้วดูภาพถ่ายสด กรอบการตรวจจับ และระดับความมั่นใจของ AI ขึ้นบนหน้าจอคอมพิวเตอร์แบบเรียลไทม์
